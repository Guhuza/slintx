# Security Policy

## Supported versions

Security fixes are provided for the latest released version of SlintX. Users should upgrade before
reporting an issue as affecting a supported version.

## Reporting a vulnerability

Do not disclose vulnerability details in a public issue or pull request. Use
[GitHub's private vulnerability reporting](https://github.com/Guhuza/slintx/security/advisories/new).
If private reporting is unavailable, contact the maintainers privately through the contact channel
on their GitHub profile and include only the information needed to reproduce and assess the issue.

Please include the affected SlintX version, operating system, relevant command and configuration,
impact, and a minimal reproduction when safe to share. Do not include secrets, signing material,
or personal data.

The maintainers will acknowledge a report as soon as reasonably possible, investigate privately,
and coordinate a fix and disclosure timeline with the reporter. This project does not promise a
specific response time until maintainer coverage is established.
