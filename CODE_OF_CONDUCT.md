# Code of Conduct

SlintX aims to be a welcoming, respectful, and harassment-free project. Participants are expected
to communicate constructively, respect differing viewpoints, accept responsibility for mistakes,
and prioritize the health of the community.

Unacceptable behavior includes harassment, discriminatory or insulting language, personal attacks,
unwelcome sexual attention, and sharing another person's private information without permission.

Project maintainers may edit or remove contributions that violate these standards and may
temporarily or permanently restrict participation when necessary.

Report conduct concerns privately to the project maintainers through their GitHub profile contact
channel. For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead. Reports will be
handled as confidentially as possible.

This policy applies in project spaces and when someone is representing the project publicly.
